# 琉光塔罗 · LuminaTarot

一个纯静态的塔罗占卜网站：78 张牌意 · 洗牌抽牌 · AI 整体解读 · 学习卡牌 · 占卜历史。

## 功能

- 78 张完整牌意（大阿卡纳 + 权杖 / 圣杯 / 宝剑 / 星币），正逆位解读
- 洗牌 / 抽牌：78 张扇形展开，点击抽牌，支持「一键翻牌」
- 占卜牌阵：时间之流（3 张）、三位一体、得失之间、情感之境（5 张）
- 整体解读：接入 DeepSeek AI 生成，自动记入「历史」（最多保留 10 次，可单条删除 / 清空）
- 学习塔罗：全部 78 张牌面一览，点击查看牌意；「收藏的牌」同样可点击学习
- 今日运势：无需洗牌直出结果
- 主题：日间 / 夜间；中英文切换；程序化生成的神秘氛围纯音乐
- 全站一屏布局，仅竖向滚动，无横向滚动条

## 本地运行

```bash
python3 -m http.server 8899
# 打开 http://127.0.0.1:8899/
```

## AI 解读配置

```bash
cp js/config.example.js js/config.js
# 编辑 js/config.js，填入 DeepSeek API Key
```

> `js/config.js` 含密钥，已加入 `.gitignore`，不会被提交；仓库只保留空模板。

## 目录结构

```
index.html        页面结构
css/style.css     样式（一屏布局 / 主题 / 滚动条）
js/app.js         全部交互逻辑（洗牌、抽牌、AI 解读、学习、历史）
js/data-*.js      78 张牌的数据
assets/cards/     牌面图片
assets/sfx/       翻牌音效
```

## 说明

仅供娱乐参考。牌面图片与音效素材用于个人学习展示。
